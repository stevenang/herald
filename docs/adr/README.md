# Architecture Decision Records

Significant design decisions for Herald are recorded here as ADRs — short documents capturing the context, the options considered, the decision, and its consequences.

Format: [MADR-style](https://adr.github.io/), numbered sequentially, never deleted — a superseded ADR is marked as such and linked to its replacement.
